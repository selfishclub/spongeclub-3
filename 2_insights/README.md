# 💡 이기적공유 인사이트

서베이 결과 기반 인사이트, 배운 것, 관점, 회고 등을 **조별로 정리해서 공유하는 공간**이에요.

## 어디에 올리나요
**내 조 폴더** 안에 파일을 추가하세요: `2_insights/{내 조}/`
> 예: `2_insights/3조/AI자동화-3회차-회고.md`

파일 이름은 자유롭게 지으시면 돼요. 한 사람이 여러 개 올려도 됩니다.

## 올리는 법
작성 후 Claude Code에게 한 마디면 끝:
> "나는 N조 (닉네임)이야, 인사이트 올려줘"

(브랜치·PR 신경 안 쓰셔도 돼요 — 자동으로 처리됩니다.)
