# 💡 조별 이기적공유 인사이트

조별 이기적공유에서 나눈 내용을 **조장님이 정리해서 올리는 공간**입니다.

## 조장님께

> 티로를 활용해서 조별 이기적공유 인사이트를 올려주세요.

## 올리는 법

1. 조별 이기적공유가 끝나면, 티로에게 내용을 정리해달라고 요청하세요
2. 정리된 내용을 `2_insights/{내 조}/` 폴더에 올려주세요
3. Claude Code에게 한 마디면 끝:
   > "나는 N조 (닉네임)이야, 인사이트 올려줘"

(브랜치·PR 신경 안 쓰셔도 돼요 — 자동으로 처리됩니다.)

## 파일 위치

`2_insights/{내 조}/` 안에 파일을 추가하세요.
> 예: `2_insights/3조/3회차-이기적공유.md`
