## A · 재료

| | |
|---|---|
| 하는 일 | 온라인 셀러 (스마트스토어 · 쿠팡) |
| 남이 나에게 묻는 것 | *(안 나옴)* |
| 반복해서 해결한 것 | 국내·중국 소싱 / 자체제작과 사입 **둘 다 경험** |
| 접근 가능한 것 | 스마트스토어 · 쿠팡 판매 채널, 국내·중국 소싱처 |
| 지금 상태 | 반려동물 카테고리는 **처음** — 이쪽 고객·데이터 없음 |

> 아이디어의 출처는 직접 겪은 일이 아니라 **인스타에서 반복해서 본 장면** — 잘 못 걷는 강아지, 뱅글뱅글 도는 강아지.

## B · 고객이 내 비즈니스를 통해 느끼는 변화

| | |
|---|---|
| 형태 | 욕창 방지 매트 *(넓게는 "노령견이 편하게 생활할 수 있는 모든 것")* |
| **Before** | 2시간마다 강아지 몸을 뒤집어줘야 함 — 밤에도 |
| **After** | 그걸 안 해도 됨 |
| 대안 | **없음.** 그냥 욕창 때문에 골머리 앓으며 버팀 |
| 대체 불가 | **크기·체형을 강아지에 맞춰 만들 수 있다** (자체제작 경험) |

### 한 문장

> ## "우리는 **욕창 방지 매트**를 파는 게 아니라,
> ## **강아지의 삶의 질**을 판다."

*※ "삶의 질"은 아직 넓은 말입니다. 사는 사람은 보호자이므로, 검증을 거쳐 더 뾰족하게 다듬을 여지가 있습니다.*

## D · 주요 페르소나

| | |
|---|---|
| 한 명으로 좁히면 | **혼자 사는 30대 직장인. 15살 말티즈와 10년 넘게 같이 산 사람** |
| 지금 뭘 하다가 막혀 있나 | 낮에 회사에 가 있는 동안, **강아지가 어딘가 잘못 들어가서 못 나와 다칠까 봐** 불안함 |
| 이 변화를 왜 원하나 | 혼자라서 낮 동안 봐줄 사람이 없음 |

## 이 변화가 시작되는 첫 지점

> **누워 있는 시간을 안전하게 만드는 것.**
>
> 대화에서 두 갈래가 나왔습니다 — ① 욕창(계속 누워 있어서 생기는 것) ② 갇힘(뱅글뱅글 돌다가 못 나오는 것).
> 둘 다 **"보호자가 자리를 비운 동안"** 에 일어난다는 공통점이 있습니다.

> **이 변화가 시작되는 첫 지점이 바로 고객에게 제공될 아이템입니다.**
> 지금 정하지 않습니다.

## 아직 비어 있는 것

- [ ] **실제 노령견 보호자를 만나본 적이 없음** — 주변에 아는 사람 없음. 어디서 만날지 정해야 함
- [ ] **경쟁 제품 조사 안 됨** — 사람용 욕창 매트 / 반려동물 방석과 무엇이 다른지
- [ ] **"강아지의 삶의 질"이 넓음** — 보호자 언어로 좁힐 필요
- [ ] **남이 나에게 묻는 것** — 재료 칸이 비어 있음
- [ ] **욕창이냐 갇힘이냐** — 두 문제 중 어디서 시작할지 미정
