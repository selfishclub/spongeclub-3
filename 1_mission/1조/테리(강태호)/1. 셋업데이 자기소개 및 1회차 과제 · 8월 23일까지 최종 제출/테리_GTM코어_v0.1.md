## A · 재료

| | |
|---|---|
| 하는 일 | 공조 엔지니어링 중소기업 관리 업무 — 인사 · 총무 · 재무 |
| 남이 나에게 묻는 것 | **회사 운영 자금** · **사람 채용** |
| 공짜로 해준 것 | 소셜 섹터 창업 경험을 바탕으로 신규 창업 대표 멘토링 |
| 반복해서 해결한 것 | "이 사업이 잘될 방법" 상담 — 창업 경험 + 오래 다닌 직장 경험을 함께 얹어서 |
| 접근 가능한 것 | 소셜 섹터 액셀러레이팅 회사의 **협력 멘토** (현재도 간헐적으로 진행 중) |

## B · 고객이 내 비즈니스를 통해 느끼는 변화

| | |
|---|---|
| 형태 | 멘토링 |
| **Before** | 사회적 가치와 비즈니스 모델 · 수익 모델 사이에서 혼란 |
| **After** | 어떤 방향으로 추진해야 할지 방향성이 정리된다 |
| 대안 | 다른 액셀러레이터의 컨설팅, 또는 지원사업 교육 |
| 대체 불가 | 일반 기업 · 창업 · 소셜 섹터 세 자리를 다 앉아봤고, **소셜 섹터에서 실제로 투자를 유치해본 경험**이 있다. 그래서 일반적인 소셜 섹터 조언보다 큰 그림과 경쟁력 있는 이야기를 할 수 있다 |

### 한 문장

> ## "우리는 **멘토링**을 파는 게 아니라,
> ## **소셜 섹터에서도 투자받을 수 있는 사업의 큰 그림**을 판다."

| | |

> 이건 카피가 아닙니다. 밖에 내거는 문장은 다음 단계에서 만듭니다.

## D · 주요 페르소나

| | |
|---|---|
| 한 명으로 좁히면 | **창업 2년차 소셜 섹터 창업가.** 팀원 2~3명, 매출이 막 나오기 시작해 연구개발을 진행 중. 아직 매출이 작아 **주로 지원금으로 사업을 꾸려가는 단계** |
| 지금 뭘 하다가 막혀 있나 | **투자를 받고 싶은데, 어떻게 준비해야 할지 모르는 상태** |
| 이 변화를 왜 원하나 | 지원금은 끊기는 시점이 정해져 있는데 매출이 아직 그 자리를 못 메운다. 자금을 만들어 사업에 집중하고 싶다 |

## 이 변화가 시작되는 첫 지점

> **「투자를 받으려면 무엇을 준비해야 하는가」**

이 대표가 지금 정확히 그 앞에서 멈춰 있습니다. 변화는 여기서 시작됩니다.

> **이 변화가 시작되는 첫 지점이 바로 고객에게 제공될 아이템입니다.**

## 아직 비어 있는 것

- [ ] **형태의 구체화** — 멘토링이라고만 잡혀 있음. 1회성인지 · 몇 주 과정인지 · 1:1인지 그룹인지 미정
- [ ] **가격** — 지금까지는 전부 무료로 해왔음
- [ ] **채널** — 액셀러레이터 협력 멘토 경로가 있지만, 기관을 통할지 개인 대표를 직접 만날지 미정
- [ ] **A의 「지금 상태」 칸** — 아직 판 적이 없어 숫자가 없음 (유형 1이므로 정상)
- [ ] **씨앗과 실제 코어의 간격** — 씨앗은 「초기 창업 대표의 사람과 돈」으로 골랐는데, 인터뷰를 통과하며 중심이 **「소셜 섹터 대표의 투자 준비」**로 좁혀졌음. 사람·조직 세팅 재료(인사·총무·재무 실무)는 아직 코어에 안 들어와 있음 — 나중에 붙일 여지
