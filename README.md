## 📤 올리는 법 (매번 이 순서대로)

**① 최신 내용 받기 (git pull)**
- Claude Code에 시키기: `"git pull 해줘"`
- VS Code: Source Control 패널 → `···` 메뉴 → **Pull**

**② 내 파일 작성**
- `1_mission/{내 조}/{내 이름}/` 안에서 `자기소개.md` 나 해당 회차 `submission.md` 작성
- 이미지는 그 `.md` 파일과 **같은 폴더**에 넣고 `![](파일이름.png)` 으로 불러오면 돼요
- Claude Code에 시키기: `"2회차 submission 작성해줘"`

**③ 올리기 (commit + push)**
- Claude Code에 시키기: `"방금 작성한 거 커밋하고 푸시해줘"`
- VS Code: 변경 파일 옆 `+` 로 Stage → 메시지 입력 후 **Commit** → **Sync Changes**(Push)

> **과제 말고 다른 걸 올릴 때도 똑같아요.** pull → 작성 → commit + push. 이 세 박자만 익히면 됩니다.

## 🗂 구글 드라이브 대신 여기를 써보려고 해요

지금까지 자료가 드라이브·슬랙·노션에 흩어져 있었어요. **3기는 여기로 모아봅니다.**

| | 왜 |
|---|---|
| **클로드 코드가 바로 읽어요** | ← 제일 큰 이유. 드라이브 파일은 못 읽지만, 여기 있는 건 *"이 폴더 읽고 정리해줘"* 가 됩니다 |
| **한 곳만 보면 돼요** | 링크를 찾아 헤매지 않아요 |
| **누가 언제 뭘 바꿨는지 남아요** | 되돌릴 수도 있고요 |
| **검색이 돼요** | 위쪽 `Go to file` 이나 `/` 로 저장소 전체 검색 |

**한 번에 다 옮기자는 게 아니에요.** 이번 기수 동안 **여기를 먼저 열어보는 습관**만 들이면 충분합니다.
낯설면 낯선 대로 올려주세요. 형식 안 맞아도 괜찮아요. **올라와 있는 게 안 올라온 것보다 훨씬 낫습니다.**

```

    └── 닉네임(이름)/                                  ← 내 닉네임(이름) 폴더
        ├── 시작하기.md                               ← 먼저 읽어보세요
        ├── 1. 셋업데이 자기소개 및 1회차 과제 · 8월 23일까지 최종 제출/

        ├── 4. 4회차 과제 · 5회차 9월 6일까지 제출/
```
