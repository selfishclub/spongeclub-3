# spongeclub-3

스폰지클럽 3기에 오신 걸 환영해요 👋 **여기는 과제를 올리는 곳이에요.**

## ⏩ 가장 먼저 할 일

**내 폴더 `1_mission/{내 조}/{내 이름}/` 을 찾아, `1. 셋업데이 …/자기소개.md` 를 작성하세요.** 이게 첫 미션이에요!
셋업데이 때 1차로 올리고, **8월 23일까지 최종 제출**입니다.
(내 조·이름은 [1_mission/README.md](1_mission/README.md)에서 확인)

## 📤 올리는 법 (매번 이 순서대로)

**① 최신 내용 받기 (git pull)**
- Claude Code에 시키기: `"git pull 해줘"`
- VS Code: Source Control 패널 → `···` 메뉴 → **Pull**

**② 내 파일 작성**
- `1_mission/{내 조}/{내 이름}/` 안에서 `자기소개.md` 나 해당 회차 `submission.md` 작성
- 이미지는 그 `.md` 파일과 **같은 폴더**에 넣고 `![](파일이름.png)` 으로 불러오면 돼요
- Claude Code에 시키기: `"2회차 submission 작성해줘"`

**③ 올리기 (commit + push)**
- Claude Code에 시키기: `"방금 작성한 거 커밋하고 푸시해줘"`
- VS Code: 변경 파일 옆 `+` 로 Stage → 메시지 입력 후 **Commit** → **Sync Changes**(Push)

## 📁 폴더 구조

```
1_mission/
└── 1조/ ~ 6조/                                      ← 내 조를 찾으세요
    └── 닉네임(이름)/                                  ← 내 닉네임(이름) 폴더
        ├── 시작하기.md                               ← 먼저 읽어보세요
        ├── 1. 셋업데이 자기소개 및 1회차 과제 · 8월 23일까지 최종 제출/
        │   └── 자기소개.md                           ← 가장 먼저 작성
        ├── 2. 2회차 과제 · 3회차 8월 30일까지 제출/
        │   └── submission.md                        ← 과제 작성
        ├── 3. 3회차 과제 · 4회차 9월 5일까지 제출/
        ├── 4. 4회차 과제 · 5회차 9월 6일까지 제출/
        ├── 5. 5회차 과제 · 6회차 9월 13일까지 제출/
        └── 6. 6회차 과제 · 7회차 9월 20일까지 제출/
```

> 폴더 이름에 **마감일**이 적혀 있어요. 과제는 **다음 세션까지**가 마감이에요.
> 이미지는 `.md` 파일과 같은 폴더에 넣으면 돼요. (별도 이미지 폴더 없음)

## ⚠️ 규칙

- **내 폴더에서만** 작업해요. 남의 폴더는 건드리지 않기.
- **비밀번호·API 키**는 절대 올리지 않기.

## 🛠 막힐 때

- `command not found` → 터미널을 껐다 다시 켜기
- push가 거절됨 → 먼저 `git pull` 후 다시 push
- 그 외 에러 → 에러 화면을 그대로 복사해서 **Claude Code에 붙여넣기**
