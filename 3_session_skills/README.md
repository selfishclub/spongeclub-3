# 🎓 정규 세션 스킬

**정규 세션에서 다룬 스킬과 이야기가 쌓이는 공간**이에요.

세션이 끝나면 그날 다룬 스킬, 스킬 소개, 세션에서 나눈 이야기를 운영진이 여기에 정리해서 올립니다.
지나간 세션 내용이 궁금하거나, 못 들은 회차를 따라잡고 싶을 때 여기를 보세요.

## 여기에 올라오는 것

- **세션에서 다룬 스킬** — 그날 실습한 스킬 본체 (복붙해서 바로 설치 가능)
- **스킬 소개** — 이 스킬이 뭘 해주는지, 어떨 때 쓰면 좋은지
- **세션에서 나눈 이야기** — 왜 이 스킬을 다뤘는지, 어떤 맥락에서 나왔는지, 함께 이야기한 내용

## 폴더 구조

```
3_session_skills/
├─ README.md        ← 지금 이 파일
└─ N회차/
   ├─ README.md     ← 그 회차에서 다룬 내용 정리
   └─ {스킬이름}/
      ├─ SKILL.md   ← 스킬 본체 (복붙 설치용)
      └─ README.md  ← 뭘 해주나 · 설치법 · 예시
```

## 스킬 설치하는 법 (복붙)

1. 쓰고 싶은 `3_session_skills/N회차/{스킬이름}/` 폴더를 통째로 복사
2. 내 `~/.claude/skills/{스킬이름}/` 에 붙여넣기
3. 끝! 클로드코드에서 바로 쓰여요.

## `skills/` 폴더랑 뭐가 다른가요

| | `3_session_skills/` | `skills/` |
|---|---|---|
| 누가 올리나 | **운영진** | **선발대·크루** |
| 무엇이 올라오나 | 정규 세션에서 다룬 스킬 + 세션 이야기 | 각자 검증·디벨롭한 스킬 |
| 성격 | 다 같이 배운 것 (공통 커리큘럼) | 각자 발견한 것 (자유 기여) |

> 세션에서 배운 스킬을 내 것으로 디벨롭했다면, [`skills/`](../skills/README.md)에 올려주세요.
