# 📚 함께 스터디

**다 같이 스터디할 것들을 모아두는 공간**이에요.

혼자 보기 아까운 것, 같이 파보고 싶은 것, 나중에 꼭 봐야지 하고 저장해둔 것 —
여기에 모아두면 다 같이 봅니다.

## 여기에 올려주세요

- **읽을거리** — 아티클, 문서, 뉴스레터
- **영상** — 유튜브, 강의, 컨퍼런스 발표
- **도구** — 써보니 좋았던 서비스·툴
- **같이 파보고 싶은 주제** — "이거 아무도 모르겠는데 같이 알아볼 사람?"

> 완성된 정리가 아니어도 괜찮아요. **링크 하나 + 왜 좋은지 한 줄**이면 충분합니다.

## 올리는 법

1. `_template/스터디자료.md` 를 복사해서 `4_study/{제목}.md` 로 만들기
2. 링크랑 한 줄 소개 채우기
3. 과제 올릴 때처럼 git pull → commit → push

Claude Code에게 한 마디면 끝:
> "4_study에 이 링크 정리해서 올려줘: {URL}"

## 이미 올라온 자료에 한마디 보태고 싶다면

그 파일 맨 아래 **💬 같이 본 사람들** 칸에 자유롭게 추가해주세요.
읽고 나서 남긴 한 줄이 다음 사람에게 제일 도움이 됩니다.

## 폴더 구조

```
4_study/
├─ README.md          ← 지금 이 파일
├─ _template/
│  └─ 스터디자료.md    ← 새로 올릴 때 복사용 양식
└─ {제목}.md           ← 올린 자료들
```
